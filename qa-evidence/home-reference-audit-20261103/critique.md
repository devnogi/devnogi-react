# Memonogi home visual critique

ROUND 1

Seen in one second: 밝은 판타지 마을 배너와 큰 흰색 검색창. 제품의 정체성이나 시세 데이터보다 배경 이미지와 입력창이 먼저 보인다.

Idea (one sentence): 판타지 마을 위에 마비노기 경매장 도구를 얹는다. 이 아이디어는 다른 판타지 게임 도구에도 그대로 적용될 수 있어 메모노기만의 인상은 약하다.

Live thing: 아이템 검색.

Layout words by section: hero=full-bleed banner / features=icon list / data notice=callout / market summary=card grid / all-time record=highlight grid / monthly data=card grid

Scores: design 5.8 · usability 7.0 · creativity 5.5 · content 6.8 → raw 6.2, capped overall 6.0

Caps applied: Taste Skill inspector가 12 FAIL을 보고해 overall 6.0 상한. 실사진/제품 이미지가 1개뿐이라 design 6.5 상한. 화면의 목적을 설명하는 visible h1이 없어 usability 6.0 상한.

Top three problems:

1. 실제 가치가 첫 화면 아래에 묻힌다. 검색 다음에 상단 내비게이션과 중복되는 네 개 기능 링크와 데이터 안내가 나오고, 사용자가 보고 싶은 시세/랭킹은 그 뒤에 시작한다. 반면 mabimobi.life와 maple.gg는 검색과 인기 유저/랭킹/로그인을 같은 히어로 장면 안에 묶는다.
2. 메모노기만의 시각적 증거가 부족하다. 현재 히어로는 밝은 범용 판타지 마을이고, 큰 제품명이나 시세 데이터가 없어 첫 장면이 장식 배너처럼 보인다. 비교 사이트는 게임 고유 이미지, 로고, 캐릭터, 실시간 데이터를 결합해 출처와 목적을 즉시 알린다.
3. 한 페이지에서 너무 많은 UI 문법이 경쟁한다. 파란 로그인/활성 내비게이션, 적갈색 검색, 주황·올리브 기능 아이콘, 연두 공지, 파랑·빨강·보라·초록 랭킹, 금색 그라데이션 카드가 함께 보인다. 여기에 66.7vw 외부 카드와 60vw 내부 콘텐츠, 20px 카드 반경, 헤어라인, 그림자 카드가 섞여 하나의 시스템보다 조립된 템플릿처럼 읽힌다.

Measured evidence:

- Local 1280×720: visible search inputs 2개, 각각 672px 폭. 첫 visible heading은 18px이며 visible h1은 없다.
- Local inspector: body 14px, 12/14/16/18/20px 다섯 크기, 7 resting shadows, 6 thin rules, 6 outlined boxes, 1 gradient, 1 image, 12 FAIL / 4 WARN.
- mabimobi.life 1280×720: 1168×334 게임 이미지 안에 447px 검색과 인기 유저 패널을 결합한다.
- maple.gg 1280×720: 1265×520 게임 이미지 안에 242×50 브랜드 로고, 검색, 랭킹, 로그인 행동을 결합한다.

Highest-impact direction:

1. 히어로에서 검색 직후 실제 시세/랭킹 한 덩어리를 보여주고, 중복 기능 안내와 긴 데이터 안내는 축약하거나 아래로 내린다.
2. 흰색/옅은 회색 바탕 + 따뜻한 단일 액센트 + 데이터용 제한된 의미 색상으로 역할을 고정한다.
3. 메모노기 고유 로고/문장/게임 이미지/실시간 시장 데이터를 첫 장면에 함께 배치하고, 전체 페이지를 하나의 그리드와 하나의 카드 규칙으로 통일한다.

Limits:

- 비교는 2026-11-03 현재 1280×720 데스크톱 첫 화면과 로컬 1440/768/390 렌더를 기준으로 했다.
- 스크린샷만으로 키보드 탐색, 스크린리더 읽기 순서, 모든 상태의 접근성 준수 여부를 확정할 수 없다.
