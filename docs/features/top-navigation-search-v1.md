# 상단 통합 검색 배치 v1

사용자가 승인한 기획. 기준: main `fe5c7d7`, 2026-11-20.

## 화면과 동작

- 기존 공통 네비게이션이 있는 모든 페이지에 통합 검색창을 한 번 표시한다.
- 1280px 이상: 로고 → 기존 메뉴(도감까지) → 검색 → 모드 전환·계정 버튼.
- 1280px 미만: 로고·계정 64px / 검색 56px / 메뉴 48px의 3행.
- 검색 입력은 기존 navigation 변형(40px)을 재사용한다. 모바일에서는 전체 행 너비, 데스크탑에서는 최소 200px부터 남은 너비를 사용한다.
- 검색창은 메뉴의 가로 스크롤 영역 밖에 두어 자동완성이 잘리지 않게 한다.
- 기존 검색 Provider, 안내 문구, 자동완성, 최근 검색, 키보드 조작, 결과별 이동과 오류 처리를 유지한다. API·공개 타입 변경이나 새 의존성은 없다.
- 홈 본문 검색과 전용 여백을 제거하고 광고와 콘텐츠는 기존 콘텐츠 간격으로 연결한다.
- 공통 헤더 높이(하단 경계선 포함 169px / 65px)를 본문 여백과 커뮤니티 사이드바 sticky 위치에 적용한다. 사이드바는 헤더 아래 기존 52px 간격을 유지한다.
- 푸터의 문구를 유지하고 `기반으로 제공합니다.` 뒤에 명시적으로 줄바꿈한다. 좁은 화면의 자연스러운 추가 줄바꿈은 허용한다.

## 완료 기준

- 360, 768, 1024, 1279, 1280, 1440px에서 3행/1행 배치, 중복 검색 없음, 본문과 사이드바 가림 없음, 자동완성 잘림 없음을 확인한다.
- 라이트/다크, 비로그인/일반 회원/관리자, 긴 닉네임과 인증 배지를 확인한다.
- 홈·경매장·커뮤니티에서 검색 선택과 이동, 최근 검색과 키보드 조작, 푸터 줄바꿈을 확인한다.
- 관련 Jest와 `npm run verify`를 통과하고 실제 diff·검증 증거로 독립 검토한다.
- PR 전 main보다 새 패치 버전을 사용한다. PR 병합·운영 배포는 별도 사람 승인을 따른다.
